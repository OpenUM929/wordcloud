✅ 스타일 적용 확인 사항

  • 배경: 모든 페이지에 밝은 그라디언트 적용 (#ffffff → #f8fbff)
  • 주 색상: 파란색 (#6366f1) → 보라색 (#6366f1)
  • 제목 구분선: 보라색 테두리로 변경
  • 버튼: 보라색 + 호버 시 진한 보라색
  • 진행 바: 보라색 그라디언트
  • 포커스 효과: 보라색 기반 (입력 필드, 버튼)
  • 네비게이션: 네비게이션 목업 참조
  • 일관성: 모든 페이지에서 동일한 색상과 스타일 사용
