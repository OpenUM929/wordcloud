## 0. 이 데이터의 존재 의의 · 활용 전략 (왜 우리 폴더에 스냅샷을 두는가)

> 🧭 **핵심 한 줄: 스키마(라벨 체계·패턴·표지)는 흡수하고, 그들의 샘플·라벨은 우리 gold로 흡수하지 않는다.** 외부 군집 산출물을 우리 데이터셋의 **설계 재료**로 쓰되 **정답(gold)** 으로는 쓰지 않는다. (사용자 의도 2026-06-19: "무조건 수용이 아니라, 군집화된 좋은 재료로 분석·조합해 향후 학습 데이터셋 분류에 활용.")

### 0-1. 무엇인가 / 왜 가치 있나
`OpenUM929/leadership`은 리더십을 **관찰 가능한 행동 단위(micro `Mxx`긍/`Nxx`부)** 로 분해하고, 그 조합 패턴으로 trait를 추론하도록 **군집·정리한 외부 산출물**이다(LLM 추출 + KoE5 768-dim 벡터DB 매칭, 라벨당 ~70개 균등 ≈ 12,460 샘플). 가치는:
- **micro 온톨로지(125/178)** = 우리 검토 **코드북** + §6 무지도 군집의 **가설 골격**.
- **forbidden 목록(hard/soft)** = "긍정처럼 보이나 부정"인 **긍↔부 경계 케이스 사전** → 우리 최우선 가치와 정확히 동일한 결.
- **trait→micro 패턴(required/optional)** = 전문가 prior = **약지도 라벨링 함수(LF)**.

### 0-2. 흡수(O) / 비흡수(X) / 조건부(△) 경계
| 대상 | 판정 | 용도 / 이유 |
|------|------|-------------|
| micro·trait 라벨 체계·정의·패턴 | **O** | 코드북·LF·군집 피처 |
| forbidden(긍↔부 경계) 표지 | **O** | `hr_context_lexicon` **additive append + 회귀 게이트** 후 반영 |
| 그들 군집 결과 | **O** | 우리 군집 **대조용 가설**(트리를 데이터로 교정, §6) |
| 그들 12,460 샘플 텍스트·라벨 | **X (gold로)** | 생성·균등분포(자연 아님)·모델산출(미확정)·도메인/출처 불일치 → gold 편입 시 분포편향+규율 위반 |
| 위 샘플 | **△** | 리더십 보조헤드/전용모델 **사전학습·증강** 한정 — 도메인갭 수용 시·평가셋 격리·**사용자 결정·D5** |

### 0-3. 4-레이어 활용 (RUNBOOK §2와 연결)
1. **코드북**: 실데이터 검토 시 micro 정의를 기준 사전으로 → 검토 일관성·속도↑.
2. **약지도 LF → 검토 큐**: trait/micro 패턴으로 후보 라벨만 부여(gold 아님) → §2-3 사람 검토 큐 적재.
3. **군집 피처·가설**: micro 표지 + KoTE `top_3`(필요 시 44-vec)로 클러스터링, 그들 군집과 대조(§6 3단계).
4. **부정표지 마이닝**: `Nxx`·forbidden → lexicon NEGATIVE_MARKERS/분기 **additive**(회귀 통과 필수) → 지금 당장 긍↔부 정밀도↑.

> 💡 **현 blocker(positive gold 0) 직격 용도**: 위 ②가 검토 가속기 → 실 코퍼스 도착 시 **우리 gold 생산 속도↑**. 가드레일 0 위반으로 blocker 공략.

### 0-4. 미래 — 리더십 전용 검사 모델 가능성 (왜 버리지 않고 보존하나)
우리 KoTE 메인(감정 44) + 리더십 보조헤드와 **별개로, 리더십만 전문 검사하는 전용 분류기**로 확장할 여지가 있다. 그 경우 본 micro 온톨로지(+ 조건부 그들 샘플)가 **부트스트랩 시드**가 될 수 있다. 전제:
- (a) 실 인사 코퍼스 gold로 **검증셋 확보**(외부 샘플은 평가셋에 **절대 미혼입**),
- (b) 모든 라벨 **긍↔부 게이트 재통과**,
- (c) 출처·라이선스·프라이버시 **분리**(외부 텍스트 ≠ 우리 내부망 가명화 텍스트 — 스키마만 차용),
- (d) micro를 모델 **타깃으로 승격하려면 "문장→micro 추출기"(LLM/규칙)** 별도 구축 필요(현 KoTE는 micro를 직접 산출 못 함).
- 🟡 **사용자 고유 결정(보류)**: 전용 모델 착수 시점·범위.

### 0-5. 가드레일 (불변)
gold는 우리 코퍼스 군집으로만 · 추측 분류 금지 · 긍↔부 재게이트 · append-only/additive · **외부 텍스트 비반입(스키마만 차용)**.

## 2. 8개 이론 카테고리 (매크로 라벨 상위 묶음 — 참고)

긍정·부정 라벨이 동일한 8개 이론 축으로 대칭 구성된다:

1. 변혁적·영감적 리더십 (비전·동기부여·지적자극·카리스마·변화주도)
2. 성과·책임 관리 (목표·피드백·책임·공정인정·실행·인재육성)
3. 서번트·공감적 리더십 (경청·공감·이타·심리안전·웰빙·자기성찰)
4. 적응적·민첩 리더십 (회복력·유연성·안정감·신속결정·위기대응·실패수용)
5. 전략적 리더십 (이해관계자·글로벌·전략·참여조정·기업가·분산)
6. 디지털·혁신 리더십 (학습·데이터기반·디지털도구·AI혁신)
7. 양손잡이 리더십 (탐색·운영안정·실험장려·자원배분)
8. 윤리·진정성 리더십 (투명소통·언행일치·포용·도덕적용기·CSR)

> 이론 매핑(`trait_theory_mapping.json`)은 외부 검증용(논문/HR/감사) grounding이며 trait 번호·명칭이 구버전과 섞여 있어 **권위 있는 trait 집합은 `data/traits/trait_definitions.json`(20-trait)** 하나로 본다.
