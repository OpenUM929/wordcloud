# 작업 수렴 분석 — 순환 위험과 미탐색 공간 (260624)

> 이번 세션(군집·규칙·gold) 작업이 "특징이 비슷하다"는 관찰에 대한 메타분석.
> 결론: 수렴=검증으로는 성공이나, 이대로 파인튜닝하면 **규칙 증류(순환)** 위험 → 미탐색 66.6% + 경계 gold로 전환 필요.

## 1. 구조적 수렴 (4중 독립 확인)

| 방법 | 도출 패턴 |
|---|---|
| 규칙 마이닝 `pattern_mining` | 긍정표지+negation·결핍명사 → 개선요청·약점부재 |
| 수작업 오분류 감사 `sentiment_misclass_260624` | 개선요청·약점부재 |
| 무지도 군집 24개 `emotion_clusters_260624` | G1 약점부재·G2 개선요청·G3 역량서술 |
| 코드에 이미 있던 규칙(0623_03) | `is_no_weakness_declaration`·`has_improvement_request` |

- 화행 템플릿(약점부재+개선요청+무응답) = **전체 870,367의 21.8%(189,567)**. 인사평가가 소수 정형구로 도배됨 → 어떤 분석도 같은 걸 재발견.
- 독립 방법들의 일치 = 이 패턴이 **진짜 구조**라는 강한 검증.

## 2. 순환(circularity) 위험 — 핵심 경고

신규 그룹 **G1·G2 = 이미 있는 규칙 술어와 사실상 동일**. D4/D5에서 멤버 선별·weak 라벨을 **그 규칙으로 생성**했다.
→ 현 weak 176,483으로 파인튜닝 = **모델이 기존 규칙을 흉내내도록 증류**될 뿐, 규칙이 모르는 건 못 배움. "비슷한 작업 반복" 느낌의 실체.

## 3. 진짜 새로운 가치의 위치 (측정)

- 미피복 부분코퍼스 **484,119** 중 화행 규칙으로 설명되는 건 **33.4%(161,853)뿐**.
- **나머지 66.6%(약 322,266)는 기존 규칙이 못 잡는 미탐색 공간** ← 여기에 새 그룹·새 신호가 있다.

진짜 lift 3곳:
1. **미탐색 66.6%** 군집 심화 → 규칙 밖 새 그룹 발굴(역량서술 G3 + 잔여).
2. **사람 gold가 규칙과 갈리는 경계**(needs_human·필드충돌) → 모델에 새 신호 주입하는 유일 통로.
3. **일반화** — 그룹=규칙이어도 파인튜닝이 `rule4_default` 천장(KoTE 확신 미보정)을 제거(효과 중간).

## 4. 권고 (다음 단계)

- 파인튜닝 직진 보류. 먼저 **미탐색 322K 군집 심화**(기존 화행 술어로 잡히는 행 제외하고 재군집) → 규칙 밖 후보 발굴.
- 경계 gold는 **사람 판정**(그룹 검토 UI)으로 확보 — 규칙과 다른 신호 우선.
- weak는 학습 볼륨으로 유지하되, **gold/eval은 규칙과 독립**이어야 평가가 의미를 가짐(규칙으로 만든 라벨로 규칙 흉내 모델을 평가하면 무의미).
