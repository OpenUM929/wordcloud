## 0. 공통 전제·가드레일 (모든 레버 공통, 예외 없음)

- **핵심가치 최우선**: 긍↔부 오분류 방지가 1순위. 중립→긍정 허용. 어떤 레버도 긍↔부를 악화시키면 즉시 기각.
- **대조군 고정**: c4 라인(현 `model_out`, n_train 3979). 모든 처치는 c4 라인 대비 A/B.
- **다중런 필수**: c3_neu149 부recall 런당 편차 0.48~0.69. **최소 seed 3개 평균**으로 판정(단일런 point 금지). 견고지표 = 부recall·긍↔부 방향의 평균.
- **model_out 불가침**: 프로토타입은 별도 출력 디렉토리·저장 안 함(`save_strategy='no'`). 배포 모델(c4 라인) 덮어쓰지 않는다.
- **append-only**: 데이터 파일 수정·삭제 금지. 이 레버들은 **데이터를 안 바꾼다**(모델링만).
- **GPU 실행**: 사용자 위임하에 claude 실행. tmp 디렉토리 학습 후 정리.
- **측정 슬라이스**: baseline399·8c_hard·c3_neu149·sa_speech74 (4종). 회귀가드 = baseline·8c_hard 긍↔부 0.
- **정직한 가치 단서**: 긍↔부는 이미 ~0. 대부분 레버가 올릴 여지는 **비-inviolable 중립경계**(가치 낮음·애매). 예외 = 레버 B(긍↔부 하드 0 굳히기)는 핵심가치 직접 강화 → 가치 분명.

## A. 앙상블 (seed 소프트보팅) — 우선순위 1

**목표**: 런당 ±10pp 분산 소거 + 통상 +1~2pp 정확도. **후속 모든 실험의 정밀 측정 기반.**

**가설**: c4 라인 단일모델의 분산이 크다(대칭 근접 경계에서 seed마다 다른 오류). K개 seed의 softmax를 평균하면 경계 노이즈가 상쇄되어 분산↓·정확도↑, 긍↔부 flutter도 평균 0으로 안정.

**방법**:
- 신규 `scripts/ensemble_eval_r8_260708.py`: c4 라인(TRAIN_FILES 불변) 단일헤드를 seed {42,43,44,45,46}로 K회 학습 → 각 슬라이스 **softmax 확률** 수집 → 평균 → argmax → `metrics`.
- 단일런 5개의 개별 지표도 같이 출력(분산 정량화: acc std, 부recall std).
- 학습은 기존 `finetune_sentiment` 로직 재사용(로짓 대신 확률 저장 경로만 추가), `model_out` 미덮어씀.

**측정·성공기준**:
- 앙상블 c3_neu149 acc **> 단일런 5개 평균 + 1std** (분산 넘는 실이득).
- baseline·8c_hard 긍↔부 **0**(전 슬라이스). c3_neu149 긍↔부 ≤ 단일런 평균.
- 부산물: acc std가 단일런 대비 눈에 띄게 축소(측정 정밀화 입증).

**리스크·롤백**: 없음(측정 실험). 배포엔 K모델 소프트보팅(서빙비용 K배) 또는 **distillation**(앙상블→단일모델 증류)로 흡수 — 별도 후속.

**선행**: 없음. 즉시 가능.

## B. 비대칭 비용민감 손실 — 우선순위 2 (핵심가치 직접 강화)

**목표**: 긍↔부를 flutter 없이 **하드 0**으로 굳히고, 그 대가로 중립경계 자유도 확보.

**가설**: 현재 평범한 CE는 모든 오분류를 등가 취급 → 긍↔부가 "우연히" 0에 가깝지만 seed마다 flutter(8c 0↔1). 오분류 **거리 비용**을 손실에 넣으면(긍↔부=거리2 큰 페널티, 중립↔극성=거리1 작은 페널티) 긍↔부가 구조적으로 억제되고, 중립경계는 덜 눌려 정확도 여지.

**방법**:
- `finetune_multitask_r7`의 커스텀 손실 프레임 재사용(별도 헤드 불요, 손실만 교체).
- 손실: `L = CE(logits, y) + α · penalty`, 여기서 penalty = 극성 라벨 예제에서 **반대 극성 확률질량**
  (`y=neg`면 `p_pos`, `y=pos`면 `p_neg`)의 평균. → 긍↔부 방향만 직접 처벌(중립 방향 무처벌 = 중립→긍 허용 원칙 정렬).
- α ∈ {0.5, 1.0, 2.0} 스윕, seed 3개. λ=0(대조=평범 CE) 대비.

**측정·성공기준**:
- **긍↔부 = 0 (전 슬라이스·전 seed)** — 현 flutter(8c 0↔1, c3 1~4)보다 엄격히 개선. 이게 주 성공지표.
- c3_neu149·baseline acc가 대조 대비 **비열화**(중립 자유도가 손해로 안 나타남). 이상적으론 소폭↑.
- α 과대 시 중립→극성 과교정 감시(c7 λ=0.3의 −6pp 재발 여부) → 최소 α 채택.

**리스크·롤백**: α 과대 시 중립 정확도 하락(c7 교훈). 스윕으로 최소 유효 α 선택, 악화 시 기각(model_out 불변이라 롤백 자동).

**선행**: A(측정 기반) 권장. 독립 실행도 가능.

## C. 사후 캘리브레이션 + 임계값 튜닝 — 우선순위 3 (재학습 0·즉시)

**목표**: 재학습 없이 **작동점(operating point)을 명시적으로 선택**. c5·c6·c7이 재학습으로 밀던 "중→부 vs 중→긍" 트레이드오프를 임계값으로 직접 제어.

**가설**: 모델은 경계에서 **과신·miscalibrated**(conf 0.9 오답 다수, c6 진단서 확인). temperature scaling으로 캘리브레이션 후, argmax 대신 **3-way 결정 임계값**을 비즈니스 목적함수로 튜닝하면 표현 재학습 없이 최적 작동점 확보.

**방법** (전부 사후, 학습된 c4 라인 또는 A의 앙상블 위에서):
1. held-out validation 분리(테스트셋 누수 없이 train 일부 홀드 or 별도 dev).
2. **Temperature scaling**: dev NLL 최소화로 T 1개 파라미터 적합.
3. **임계값 튜닝**: "부정이라 부르려면 `p_neg - p_neu > τ_neg`, 긍정은 `p_pos - p_neu > τ_pos`, 아니면 중립" 형태의 τ를 그리드 탐색. 목적 = **긍↔부=0 하드제약 하에서 acc 최대**.
4. serve 규약에 T·τ 반영(추론 후처리 1회).

**측정·성공기준**:
- 긍↔부 0 유지하면서 c3_neu149 acc ≥ 대조(argmax). 작동점 곡선(τ vs 긍↔부/중recall/부recall) 제시.
- ECE(calibration error) 개선 수치.

**리스크·롤백**: 낮음(사후·가역). dev 과적합 방지 위해 τ는 거친 그리드·소수 파라미터만. 배포는 후처리 상수라 즉시 롤백.

**선행**: 학습된 모델 1개(c4 라인) 있으면 됨. A와 결합 시 앙상블 확률에 적용.

## D. 2단계 캐스케이드 (보조) — 신호 보이면

**목표**: 하드클래스(중립)를 전용 판별기로 분리해 경계 정확도↑.

**가설**: 긍↔부는 이미 쉬움. 어려운 건 "평가적(극성) vs 비평가적(중립)" 1차 경계. 이를 전용 2분류(평가/중립)로 먼저 풀고, 평가로 판정된 것만 긍/부 2분류 → 각 서브문제가 단순해짐.

**방법**: 헤드 2개(gate: 극성-vs-중립 / polarity: 긍-vs-부) 또는 순차 2모델. gate 통과분만 polarity 적용. 최종 = gate=중립이면 중립, 아니면 polarity.

**측정·성공**: c3_neu149 중recall + 부recall 동시 개선, 긍↔부 0. 대조=단일 3분류.

**리스크**: gate 오류가 하류 전파(중립 놓치면 강제 극성화 → 긍↔부 위험). gate를 중립-보수(의심시 중립)로 튜닝 필수.

## E. 대조학습 (보조) — c7보다 정교한 화행분리

**목표**: field-조건 극성을 날카롭게 — 단점"보완 필요"(부) ↔ 장점"보완함"(긍) 페어를 표현공간에서 분리.

**가설**: c7 멀티태스크 CE는 화행을 "분류"만 했다. **contrastive**(같은 극성 당기고 반대 극성 밀기, 특히 공유토큰 페어)는 표현을 직접 성형해 요청/실현 분리를 더 강하게.

**방법**: supervised contrastive loss를 극성 라벨(또는 공유토큰 하드페어)로 추가. `L = CE + β·SupCon`. 하드페어 마이닝 = 같은 명사·다른 field·다른 극성(감사에서 이미 확인된 보완/고집/과도 페어).

**측정·성공**: c3_neu149·sa_speech74 부recall↑ 동시에 중립 비열화, 긍↔부 0. 대조=CE only.

**리스크**: 배치 구성·튜닝 민감. c7이 순이득 없었으므로 기대치 보수적.

## F. 베이스 인코더 A/B (보조) — 마지막 확인

**목표**: KoTE(감정 멀티라벨 프리트레인)가 3분류에 최적인지 검증.

**가설**: KoTE는 44감정 프리트레인이라 3분류 경계에 오히려 편향일 수 있다. 범용 한국어(KLUE-RoBERTa-base, KoELECTRA)가 더 붙을 여지.

**방법**: 동일 TRAIN·field-token으로 base만 교체 A/B, seed 3개. 도메인 적합성 vs 범용성 비교.

**측정·성공**: 4슬라이스 전반 acc·부recall이 KoTE 대비 우위 + 긍↔부 0. 유의미하면 base 교체 검토.

**리스크**: 도메인 프리트레인(KoTE) 상실로 오히려 하락 가능. 순수 탐색.

## 종합 판정 기준 (공통)

각 레버는 아래를 **동시** 만족해야 채택:
1. **긍↔부**: baseline·8c_hard 전 seed 0 (절대). c3_neu149 ≤ 대조.
2. **순이득**: c3_neu149 또는 sa_speech74 지표가 **단일런 분산(1std)을 넘는** 실개선.
3. **비열화**: 어느 슬라이스도 acc 유의 하락 없음.
셋 중 하나라도 실패 시 기각(model_out 불변이라 롤백 자동). 채택 시 IMPROVEMENT_HISTORY에 3부 표준(①기대→②실제→③성찰)으로 DN 기록.

## DN 정책

- 각 레버 = **실측(다중런) 완료 후에만 DN**. 그 전까지 PND + 위 체크리스트.
- 프로토타입은 `model_out` 미덮어씀 → 배포 확정은 별도(채택된 레버만 c4 라인 위에 재현·저장).
