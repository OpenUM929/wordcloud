## 3. 계획서 대비 변경/차이점

### 추가 구현 (계획서에 명시되지 않았으나 실제 구현)

| 항목 | 설명 |
|------|------|
| **전역 `fetch()` 인터셉터** | 계획서에는 "세션 만료 리스크" 언급만 있었으나, `window.fetch` 래핑으로 모든 API 401 응답 시 모달 자동 재표시 구현 |
| **`globalAuthPwInput` focus 딜레이** | 모달 표시 후 즉시 입력 필드 포커스 (`setTimeout 50ms`) — UX 개선 |

### 구현 방식 차이

| 항목 | 계획서 | 실제 구현 | 이유 |
|------|--------|-----------|------|
| `generate_all_employee_matrix()` 필터 | `for eid in employee_ids` 순차 비교 | `set(resolved_filter)` 집합 교집합 | 성능 개선 (O(n) → O(1) 조회) |
| `employee_id_real` 필드 | `real_id != employee_id` 조건 시만 추가 | `real_id != resolved_id` 조건으로 수정 | `resolved_id` 기준으로 비교해야 정확 |
