## 1. 작업 요약

현재 갤러리(`deploy_gallery.html`)는 **제출용 저장(`save_to_deploy`) 결과**만 조회 가능했습니다.

이번 작업에서는 다음 기능을 구현했습니다:

1. **매트릭스 생성 결과 자동 인덱싱** — `generate_perspective_matrix()` 호출 시 결과를 `deploy_manifest.json`에 자동으로 기록
2. **상세보기 출처 탭 분리** — "제출용 저장" / "매트릭스" 탭으로 분리하여 조회
3. **칩 필터(Chip)** — 통합/긍정/부정 + 동적 연도(데이터 기반) 다중 선택 필터링
4. **오름차순 정렬** — 연도 기준 오름차순, 같은 연도 내에서는 통합→긍정→부정 순
5. **출처 배지 표시** — 갤러리 카드에 '제출용' / '매트릭스' 배지 추가

## 3. 상세 변경 내용

### 3.1 `src/services/perspective_service.py`

#### `_index_matrix_to_manifest()` — 신규 함수

매트릭스 결과를 `deploy_manifest.json`에 인덱싱합니다.

- `matrix[year][first_col]['nlp']['wordcloud_url']`에서 combined 이미지 URL 추출
- `row_results[year] = {combined: url, positive: null, negative: null}` 구조로 저장
- 썸네일: 첫 번째 행의 combined 이미지 사용
- `source: "matrix"` 필드 포함
- 기존 `_write_manifest_entry()` 재사용 (FileLock 포함)

#### `generate_perspective_matrix()` — 인덱싱 호출 추가

```python
# return result 직전
if result.get('matrix') and result.get('rows'):
    _index_matrix_to_manifest(result, employee_id, row_field, col_mode, analysis_type, options)

return result
```

- 단일 직원 호출 시에만 인덱싱 (`all_employees=True`는 별도 흐름에서 처리, Out-of-Scope)

### 3.2 `src/routes/perspective_routes.py`

#### `api_deploy_gallery_list()` — 수정

1. **`source` query parameter 추가**
   - `?source=deploy` 또는 `?source=matrix` 필터링 가능
   - 역호환: 기존 엔트리에 `source` 필드 없으면 `'deploy'`로 간주

2. **`image_count` 수정**
   - 기존: `sum(1 for v in images.values() if v)` (최상위 images만)
   - 변경: `top_count + row_count` (최상위 + row_results 전체 합산)

3. **`source` 필드 추가 반환**
   - 응답의 각 entry에 `source` 필드 포함

#### `api_employee_entries()` — 신규 엔드포인트

```
GET /api/perspective/deploy-gallery/employee-entries/<employee_id>
```

- 같은 직원의 `deploy` / `matrix` 양쪽 **최신 entry**를 각 1건씩 반환
- 타임스탬프 문자열 비교(`YYYYmmdd_HHMMSS`)로 최신 판단
- 비관리자는 `real` 모드 데이터 제외
- 한쪽이 없으면 `null` 반환

## 6. 알려진 제한사항

1. **매트릭스 긍정/부정 이미지 미생성**
   - 현재 매트릭스 셀은 `combined`만 생성합니다.
   - `row_results[year].positive` / `.negative`는 항상 `null`입니다.
   - 별도 생성이 필요하면 별도 계획서가 필요합니다.

2. **직원별 최신 1건만 조회**
   - `employee-entries` API는 같은 직원의 동일 source 중 **타임스탬프 기준 최신 1건**만 반환합니다.
   - 과거 매트릭스 결과를 모두 보고 싶다면 목록 필터(`?source=matrix&employee_id=xxx`)를 사용하세요.

3. **칩 스타일 충돌 가능성**
   - `.chip`, `.chip--active`, `.chip--disabled` 클래스는 프로젝트 전체에서 **처음 사용**되는 클래스입니다.
   - 향후 다른 페이지에서 동일한 클래스를 사용할 때 스타일 충돌 가능성이 있습니다.
