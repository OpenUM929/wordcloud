# [원페이퍼] 다면평가 감정분석 AI — 도입 검토 요약

> **1장 요약본** · 2026-07-15 · 대상: 인사처·경영진 · 상세는 [기술설명서](기술설명서_260715.md)·[스펙설명서](스펙설명서_260715.md)

### ■ 무엇인가
다면평가 자유서술 코멘트를 읽고 **긍정 / 부정 / 중립**으로 자동 분류하는 AI(배포본 "**7/8 모델**").

### ■ 무엇이 달라지나 (Before → After)
| | 도입 전 | 도입 후 |
|---|---|---|
| 방식 | 장점/단점 칸 글자를 **워드클라우드**로만 | 문장 **뜻을 읽어** 판정 |
| 극성 | "어느 칸에 썼나"로만 가정 | 문장별 긍/부/중 판정 |
| 산출 | 단어 빈도뿐 | 긍/부/중 **비율·부서 비교·추세** |

### ■ 핵심 성적 (사람이 매긴 정답 762건 기준)
| 검증셋 | 정확도 | 칭찬↔불만 오류 |
|---|---:|:---:|
| 일반 대표 | **97.7%** | **0** |
| 혼합·고난도 | **90.7%** | **0** |
| 중립 경계 | 76.5% | 3 |
| 개선요청·완곡 | **83.8%** | **0** |

- **가장 치명적인 "칭찬↔불만 뒤바뀜" = 0건**(중립경계 제외 전 구간). 직원이 억울해지는 사고를 최우선으로 막음.
- **운영 실적**: 최근 배치에서 **270만 문장을 98.8% 판정 완료**(긍 59% / 중 23% / 부 16%).

### ■ 왜 이 모델인가 (대안 전부 열세)
데이터 추가·규칙패턴·판정패킷·**3배 큰 모델**·큰 모델+대량정제 — **모두 7/8에 패배**(칭찬↔불만 오류 발생 또는 정확도 하락). "게을러서 멈춘 게 아니라, 더 나은 게 없어 확정".

### ■ 공정성 — 어떻게 쓰나 (가장 중요)
- AI 판정은 **부서·조직 단위 참고용 집계 지표**(비율·추세·부서비교)로만 쓴다. **개별 직원 인사점수에 자동 직접 반영하지 않는다.** 최종 판단은 사람이 한다.
- 오류 발견 시 담당자가 **직접 정정**(사람 확정=gold)하고, 정정분은 다음 재학습에 반영된다. 못 판정한 1.2%는 버리지 않고 **보류**로 남겨 필요 시 사람이 본다.
- ※ "직접 반영/참고용" 최종 정책은 인사처가 확정. (상세: 기술설명서 §7-3~7-5)

### ■ 정직하게 밝히는 한계
- **중립 경계 76.5%**는 낮다. 단, "노력의 여지가 있음"처럼 **사람도 갈리는 회색지대**다(사람 한계선 측정으로 증명 예정).
- **천장 확증(2회)**: 데이터·모델을 더해도 안 오름.

### ■ 남은 유일한 개선 후보
**도메인 이어사전학습(DAPT)** — 우리 원문 270만으로 바탕모델을 우리 말투에 더 적응시키는 방법. **정답 불필요(넘치는 원문 사용)**, 기대는 완만·보장 없음. GPU 승인 시 1회 시험.

### ■ 객관적 위치 & 논문화
- **객관 잣대**: ① 바탕모델(KoTE)은 공개 벤치마크(NSMC)에서 약 90%급 = 검증된 재료 ② 독립 앵커·③ 사람 한계선 측정 예정. (과제가 달라 공개점수와 직접 우열 비교는 안 함.)
- **논문화**: 응용 NLP 워크숍/국내학회/기술보고서 수준 **가능**. 최상위 학회는 관측자 일치도·데이터 공개 보강 필요(재작업 아닌 추가).

### ■ 권고
- **7/8 모델 동결·도입 진행.** 정확도 목적의 데이터 누적은 중단, DAPT 1회 시험만 남겨둠.
- 회귀 감시: 4종 검증셋에서 **칭찬↔불만 0 유지** 지속 확인.
