## 1. 결과 보고서 — 「그래서 뭐가 좋아졌나」

| 절 | 이 절을 읽고 독자가 알게 되는 것(한 문장) | 근거가 되는 표·그림 |
|---|---|---|
| 1-1 | **사람이 다 읽을 수 없던 양을 전수로 읽어냈다** — 265만 문장은 사람 판독으로는 도달 불가능한 규모였다 | 표: 3개 연도 배치 규모 · 사람 판독 소요 추정 대비 |
| 1-2 | **칭찬을 불만으로 뒤집는 오류가 사라졌다** — 이 시스템이 절대 하면 안 되는 단 하나의 오류가 네 시험지 전부에서 0건이다 | 표: 혼동 행렬 2벌(종전/현행) · 대각 반대편 0 강조 |
| 1-3 | **열에 아홉을 맞히던 것이 백에 아흔여덟이 되었다** — 실제 분포에 가까운 시험지에서 82.4% → 97.7% | 표: 도입 전 · 현행 2행 |
| 1-4 | **단계별로 무엇을 했고 무엇이 남았는지 한눈에 보인다** (구본 §2-2 「조치 요청 사항」의 대체) | **흐름도**: 단계 줄기 → 수행·결과 가지 |
| 1-5 | **남은 오류는 「긍정이냐 중립이냐」 한 자리에만 몰려 있다** — 위험한 자리가 아니라 무해한 자리에 남았다 | 표: 오류 69건 유형별 · 1행 = 1유형 |
| 1-6 | **표본을 100배로 키워도 결론이 흔들리지 않았다** — 400건과 76만 건이 같은 답을 준다 | 표: 규모별 3행(400 / 76만 / 265만) |

**탈락·이관** — 「측정 체계의 여섯 눈금」(구본 §Ⅲ)은 결재자가 그것으로 **무엇을 판단하는지 한 문장으로 못 쓴다** → 문서 3 으로. 「이력」·「한계」 전량 → 문서 5·6 으로(INS-8).

## 2. 결과비교 보고서 — 「왜 마지막 판이 아니라 7/8 판인가」

> 🔴 사용자 지적 11번의 직접 대응 문서. **결론을 §2-1 에 놓고, 근거는 뒤로 뺀다.**

| 절 | 이 절을 읽고 독자가 알게 되는 것(한 문장) | 근거가 되는 표·그림 |
|---|---|---|
| 2-1 | **가장 좋은 판은 마지막에 만든 판이 아니라 7월 8일 판이다** — 이후 만든 것이 전부 이보다 못했다 | 표: 5개 후보 × 4개 시험지 한 장 |
| 2-2 | **더 만들어 본 6종이 하나도 배포본을 넘지 못했다** — 「안 해본 것」이 아니라 「해보고 기각한 것」이다 | 표: 후보별 채택/기각 1행씩 + 기각 사유 1개 |
| 2-3 | **공개 모델을 그대로 쓰면 도입 전보다 오히려 나빠진다** — 82.4% → 78.4%, 뒤바뀜 23 → 36 | 표: 3행(도입 전 / 공개 모델 / 현행) |
| 2-4 | **정답을 더 넣었는데 성적이 떨어졌다** — 데이터를 늘리는 방향은 이미 한계에 닿았다 | **흐름도**: 후보 → 판정 근거 → 채택/기각 (INS-3 §3) |
| 2-5 | **바꾸지 않기로 한 결정에도 근거가 남아 있다** — 동결은 방치가 아니라 판정 결과다 | 표: 동결 결정일 · 재검토 조건 |

**정본·인용** — 수치 정본은 [`MODEL_SELECTION_REPORT_260715.md`](../../../../_datasets/kote_finetune/result/MODEL_SELECTION_REPORT_260715.md) §4. 이 문서는 **인용만 하고 재계산하지 않는다**(INS-9 §6).
**반드시 정정본으로 실을 것** — 「교정 62건 재학습 기각」은 틀린 요약이다(`_FACTS.md` C-011). 62건은 A/B 대상이 아니라 홀드아웃 하위 층이므로 **문서 4 로 보낸다.**

## 3. 기술 검토서 — 「그 수치를 믿어도 되나」

| 절 | 이 절을 읽고 독자가 알게 되는 것(한 문장) | 근거가 되는 표·그림 |
|---|---|---|
| 3-1 | **눈금마다 답할 수 있는 질문이 다르다** — 어떤 수치는 실력을, 어떤 수치는 실태를 재며 서로 대신하지 못한다 | 표: 눈금 × **「이것으로 무엇을 판단하나」** 열 필수(INS-7) |
| 3-2 | **정확도의 대표값은 하나뿐이다** — 여러 수치가 도는 이유는 시험지가 여러 장이기 때문이다 | 표: 시험지별 값 + 대표값 지정 1행 |
| 3-3 | **오차 범위를 감안해도 결론은 뒤집히지 않는다** | 표: 보정 신뢰구간 |
| 3-4 | **채점자와 시스템의 일치도가 우연 수준을 크게 넘는다** | 표: 카파 종전/현행 |
| 3-5 | **산출물이 정말 그 모델의 출력인지 다시 돌려 확인했다** | 표: 재현 검정 대조 |

**⚠ 이 문서에만 적용되는 제약** — 구본 Ⅳ장(756줄, 전체의 46.0%)이 여기로 온다. **그대로 옮기면 분할의 의미가 없다.** 위 5절에 들어가지 않는 내용은 문서 4 로 보내거나 버린다.

## 4. 시험데이터 산정 보고서 — 「무엇으로 채점했나」

| 절 | 이 절을 읽고 독자가 알게 되는 것(한 문장) | 근거가 되는 표·그림 |
|---|---|---|
| 4-1 | **시험지는 네 장이고 각각 다른 약점을 노린다** — 한 장으로는 실력을 알 수 없어서 나눴다 | 표: 4개 셋 × 성격 × 크기 |
| 4-2 | **채점 분모는 파일 762행 중 761건이다** — 3분류 대상이 아닌 1건을 뺀 값이며, 두 수가 도는 이유가 이것이다 | 표: 파일 행 ↔ 채점 대상 대조 4행 + 계 |
| 4-3 | **채점에 쓴 정답 칸은 `human_decision` 이다** — 같은 파일의 `gold` 칸은 옛 값이라 쓰면 안 된다 | 표: 필드별 분포 대조 |
| 4-4 | **무작위 400건은 모집단을 대표할 자격이 있다** | 표: 적격성 판정 항목별 |
| 4-5 | **가장 어려운 88건에서는 셋에 하나만 맞는다** — 한계를 감추지 않고 이 자리에 적는다 | 표: 홀드아웃 층별(62건 포함) |

**신규 확정 사실** — 4-2·4-3 은 2026-08-11 원자료 파싱으로 새로 확정했다(`_FACTS.md` F-038~F-041). 구본에는 없던 내용이며, **F-037 로 열려 있던 불일치를 닫는다.**
