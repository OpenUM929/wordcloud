## 2. 배경 및 문제 정의 (S0 — 감정 분석 도입 이전)

기존 시스템(= S0, **감정 분석이 극성 판정에 도입되기 이전**)은 사용자가 입력한 텍스트를 **장점/단점 라벨에 따라 그대로 감정 극성으로 확정**했다. 장점 라벨에 적힌 내용은 무조건 긍정, 단점 라벨에 적힌 내용은 무조건 부정으로 처리되었으며, 실제 문맥이나 의미에 대한 검증 과정이 없었다.

이 방식은 다음 한계를 가진다.

- 입력 위치와 실제 의미가 불일치하는 경우를 구분하지 못함
- 동일한 단어라도 문맥에 따라 전혀 다른 의미를 가질 수 있음에도 이를 반영하지 못함

**예시**: "협의", "공감"이라는 단어만 입력된 경우

- 장점 라벨에 적혔다면 → 실제로 긍정적 특성으로 해석 가능
- 단점 라벨에 적혔다면 → 단점이 아니라 "필요 능력(보완이 필요한 역량)"으로 해석하는 것이 문맥상 더 타당함

```
   │      argmax 라벨 불변, 신뢰도 눈금만 보정 (ECE 0.090~0.113 → 0.047~0.088)
   │
   ├─ ④ 좁은 고정밀 후처리 R1
   │      src/services/perspective_service.py:apply_model_label_override
   │      모델이 positive인데 요청표지 화행("~해주세요/~바랍니다")이면 → neutral
   │      **긍↔부를 새로 만들지 않는 방향(긍→중)으로만 동작**
   │
   ├─ ⑤ 사람 교정 반영 (sentiment_corrections, DB row id 기준)
   │
   └─ ⑥ 극성별 워드클라우드 생성
```

**설계 원칙**

- **긍↔부 불가침**: 어떤 보정 레이어도 긍정↔부정 오류를 새로 만들지 않는다. R1은 긍→중 단방향이다.
- **필드 이중계산 금지**: 필드 신호는 모델이 이미 프리픽스로 내장한다. 후처리에서 필드 극성을 재적용하는 안은 실증 후 폐기했다(4슬라이스 긍↔부 +2, 정확도 급락 — `plans/2026/07/13_03_rule-alignment/`).
- **무중단 폴백**: 모델 디렉터리 부재·로드 실패·추론 예외 시 `None`을 반환해 기존 규칙 경로로 자동 폴백한다.

지배적 실패 유형은 **개선요청 화행을 긍정으로 읽는 것**(negative→positive 40건)이다. "직무분야에 대한 전문지식이 더 필요함", "직원 간 화합이 필요", "도전적 목표 설정과 과감한 도전필요" 등 — 문장 내 긍정 어휘(전문지식·화합·도전)가 화행 극성을 압도한다. **S2 규칙 엔진이 이 55건 중 36건을 교정**하고, 나머지는 파인튜닝 단계에서 흡수된다.

부정어의 부정 계열은 S1이 전건 반전시킨다 — "고압적인 태도를 보이지 않음" / "권위의식이 없음" / "강압적이지 않음" 3건 모두 S1=negative, S2=positive, S10=positive(0.67~0.83). 어휘집 구축 시 실측 근거(475문장)에서 부정 표지 문장 11건 중 진짜 부정은 4건 수준이었고 나머지가 이 계열이다.

**학습 정답지의 출처 — S3 이후 "사람 gold"가 무엇인가**

| 구분 | 규모 | 용도 | 학습 투입 |

S3 시점 학습분은 1,579건이며 S10까지 4,016건으로 누적되었다. 🔴 **정정(2026-07-30): 눈금 ②는 학습에 8건이 투입되어 있었다**(문장만 일치는 15건, 눈금 ③은 1건). 이전 판의 "한 건도 투입되지 않았다"는 사실과 다르다. **다만 "분리가 깨지면 §4-6 표 전체가 무효"라는 조건문은 성립하지 않는다** — 오염률 2.0%에서 중복분을 제외하면 일치율이 93.50% → 93.88%로 **오르며**(n=8이라 방향 판정은 불가), 표의 결론은 유지된다. 정확한 상태는 **"분리 원칙은 유효하나 2.0% 누출이 있었고 고지한다"** 이다(구판 고지 ②).

**정직 고지 — 이 표를 읽을 때 주의할 점**

- **주 눈금은 대표 검증셋(398건)이다.** 전체 761건 열은 참고용이며, 하드셋 3종은 **특정 단계 이후에 그 단계의 실패를 표적해 만들어진** 검증셋이라 그 이전 단계에 구조적으로 불리하다. 예컨대 혼합·고난도셋과 개선요청셋은 "규칙 엔진이 중립으로 버린 잔재"로 구성되어, S2(규칙) 단계는 정의상 이 셋을 거의 전부 중립으로 판정한다.
- **단조 상승이 아니다.** S4→S6 구간에서 대표셋이 93.22% → 91.96%로 내려간다. 이 구간은 하드클래스(어려운 문장) 성능을 올리는 대신 대표셋을 약간 내준 구간이며, 실제로 같은 구간에서 전체 761 정확도는 73.85% → 78.71%로 올랐다. **한 지표만 보면 개선을 오독한다.**
- S1(KoTE 단독)과 S2(규칙)는 체크포인트가 아니라 현재 코드베이스의 KoTE 모델·규칙 엔진을 재실행한 값이다. 규칙 엔진은 **최종형(5차 + 결핍 중립화 반영)**이므로, 규칙 내부 1~5차의 진화는 이 표에 분해되어 있지 않다(별도 눈금 → §4-7).
- 각 체크포인트는 학습된 규약대로 채점했다(필드 프리픽스 사용 여부를 학습 조건과 일치시킴). 재현: `result/measure_stage_curve_260727.py`, `result/measure_rule_stage_260727.py`.

### 4-8. q.txt §3 지표 전체 (실측값, 눈금 3)

**① 재분류율 (Reclassification Rate)**

> 재분류율(%) = (입력 라벨과 시스템 판단이 다른 건수 ÷ 전체 입력 건수) × 100
> = 216 ÷ 761 × 100 = **28.38%**

| 슬라이스 | 재분류율 |
|---|---:|
| 일반 대표 문장셋 | 16.33% |
| 혼합·고난도 문장셋 | 50.71% |
| 중립 경계 문장셋 | 40.27% |
| 개선요청·완곡표현 | 27.03% |

**② 재해석 정확도 (Reinterpretation Accuracy)**

> 재해석 정확도(%) = (재분류가 타당하다고 확인된 건수 ÷ 전체 재분류 건수) × 100
> = 173 ÷ 216 × 100 = **80.09%**

| 재분류 결과 | 건수 | 비율(재분류 대비) |
|---|---:|---:|
| **교정** (입력 라벨이 틀렸고 시스템이 맞음) | **173** | **80.09%** |
| 유해 재분류 (입력 라벨이 맞았는데 시스템이 바꿈) | 32 | 14.81% |
| 둘 다 오답 | 11 | 5.09% |

> 유해 재분류 32건은 전체 761건 대비 **4.20%**이며, 이 중 긍↔부 방향은 **0건**이다(전부 극성↔중립 경계). 즉 재분류가 실패해도 치명 오류를 만들지 않는다.

**③ 방향성 일치율 (Direction Agreement Rate)**

> 방향성 일치율(%) = (입력 라벨과 시스템 판정이 일치한 건수 ÷ 전체) × 100 = 545 ÷ 761 × 100 = **71.62%**
> 이 일치 구간의 정확도는 **95.23%** — 시스템이 입력 라벨을 따를 때는 거의 항상 옳다.

**④ Accuracy (정확도)**

> Accuracy = 올바르게 분류된 건수 ÷ 전체 판단 건수
> 개선 = 692 ÷ 761 = **90.93%** / 기존 = 551 ÷ 761 = **72.40%**
> 대표 검증셋 기준: 개선 **97.74%** / 기존 82.41%

**⑤ Precision / Recall / F1-score (클래스별)**

| 클래스 | 기존 P | 기존 R | 기존 F1 | 개선 P | 개선 R | 개선 F1 |

**⑥ Cohen's Kappa (사람 정답과의 일치도)**

> κ = (Po − Pe) ÷ (1 − Pe)

## 9. 참고 문헌 및 이론적 근거

> 🔴 **본 절의 성격에 대한 철회 고지(2026-07-31 신설)**
> 상세 §4-10 (1) 에서 **"참조 문헌에는 준수·근거 판정이 성립하지 않는다"** 가 확정되었으나, 본 절에만 반영되지 않아 지금 반영한다.
> 아래 5건은 **논문·사례이며 규범 문서가 아니다.** 따라서 본 절은 **"같은 계열의 기법·문제의식이 문헌에 존재한다"는 유사성 진술**에 그치며, **본 시스템의 타당성·성능·제도적 정당성을 뒷받침하는 근거가 아니다.**
> ⓐ 이전 판의 **"학술적으로 뒷받침됨"** 이라는 표현을 **철회**한다. ⓑ 이전 판 말미의 **"본 보고서의 지표 설계와 문헌 대응"** 단락(방향성 일치율 71.62%를 문헌의 82.4%에 대응시킨 서술)을 **전량 철회**한다. ⓒ 아래 5건은 **원문 서지 대조 기록이 없으며**, 통상 알려진 서지사항으로 기재했을 뿐이다.

1. **문맥 기반 감정 분류의 타당성**
   신○○, 「기계학습을 이용한 Aspect-Based Sentiment Analysis 기반 전기차 요소별 사용자 감성 분석 및 예측 모델링」, 서울대학교 학위논문.
   딥러닝 기반 감성 분류 모델이 단어 자체의 의미가 아니라 문장 전체의 문맥을 파악하여 긍정/부정을 분류할 수 있음을 실증하였고, Lexicon(사전) 기반 분류와 기계학습 기반 분류 간 결과가 상당 부분(17개 Aspect 중 14개, 약 82.4%) 일치함을 확인함 → **유사성 진술**: 문맥 기반 분류라는 같은 계열의 접근이 문헌에 존재한다는 뜻일 뿐이며, **본 시스템의 타당성을 뒷받침하는 근거가 아니다**(위 철회 고지)

2. **Aspect 기반 감정 분석(ABSA)의 개념적 배경**
   Bhoi, A., & Joshi, S., *Various Approaches to Aspect-based Sentiment Analysis*, University of Illinois at Chicago (arXiv:1805.01984).
   하나의 문장·표현 안에서도 항목(aspect)에 따라 상반된 감정이 공존할 수 있다는 문제의식을 제시함 → "협의/공감"이 장점 라벨과 단점 라벨에서 다르게 해석되어야 한다는 본 프로젝트의 문제 정의와 동일한 논리 구조

3. **서술형 평가에 대한 Aspect 기반 분석 적용 사례**
   *Aspect Based Sentiment Analysis to Extract Meticulous Opinion Value*, arXiv:1405.7519.
   여러 평가자(교사)가 대상자(학생)에 대해 작성한 서술형 의견을 aspect 단위로 분석하여 opinion value를 도출하는 LOR(추천서) 시스템 사례 → 다수 평가자가 서술형 의견을 남기는 다면평가 구조와 응용 맥락이 유사

4. **다면평가 제도의 정책적/이론적 정당성**
   「다면평가의 활용 방식에 따른 유형화 연구: 정부 및 민간사례를 중심으로」, 한국행정학회(KCI).
   다면평가가 단일 평가자 중심 성과평가의 한계(개인적 편향, 공정성 문제)를 보완하는 수단으로 도입되고 있음을 제시 → **유사성 진술**: 제도적 배경 설명일 뿐이며, **본 프로젝트의 제도적 정당성을 뒷받침하는 근거가 아니다**(위 철회 고지)

5. **한국어 감정 분석 모델 관련**
   KcBERT/KcELECTRA 기반 한국어 감정 분석 파인튜닝 모델 사례 (Hugging Face, AI Hub 한국어 감정 데이터셋 활용).
