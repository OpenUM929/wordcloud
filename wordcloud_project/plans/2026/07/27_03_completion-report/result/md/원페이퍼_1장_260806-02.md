## 구축 전후 비교 (AS-IS → TO-BE)

**□ 기존 평가 방법은 사용자 평가 페이지의 장점/단점 기입 정보(이하 '라벨')를 절대값으로 처리**

○ 문장 내용은 읽지 않고 **라벨을 그대로 결과로** 집계했습니다. 단점 라벨이면 내용과 무관하게 불만 1건입니다.
예) 단점 라벨의 "보완필요점에 대해서는 특별히 없음" · "항상 열정적이며 문제해결 능력이 탁월함" → 종전 집계는 **둘 다 불만**

| 구분 | **AS-IS** — 라벨을 그대로 결과로 | **TO-BE** — 문장을 읽고 판정 |
| --- | --- | --- |
| 중립 분류 | **없음** | 신설 — 68.5만 건(25.8%, 전량) |
| **정확도** (400문장 전체) | **63.3%** | **93.5%** |
| └ 장점 라벨 204문장 | 93.1% | 96.6% |
| └ **단점 라벨 196문장** | **32.1%** | **90.3%** |
| 칭찬↔불만 뒤바뀜 | **7.8%** (31건) | **1.0%** (4건) |

○ **채점 방법** — 2024년 자료에서 무작위로 400문장을 뽑아(추출 시드 고정), 시스템 결과를 가린 채 원문만 읽고 먼저 정답을 정한 뒤 두 방식을 같은 정답으로 채점했습니다. **정답을 정한 주체는 사람이 아니라 AI 판독입니다.**
○ **종전 방식에는 정확도를 재는 기능이 없었습니다.** 63.3%는 당시 측정한 값이 아니라, 원데이터에 남아 있는 라벨로 종전 방식의 출력(장점 라벨→칭찬 / 단점 라벨→불만)을 그대로 복원해 **같은 정답으로 다시 채점한 값**입니다.
○ **63.3%는 400문장 전체의 값입니다.** 장점 라벨은 이미 93.1%로 문제가 없었고, 낮은 값은 전적으로 **단점 라벨(32.1%)**에서 나옵니다. 단점 라벨 오답 133건 중 **104건이 실제로는 중립**입니다 — 종전 구조에 **중립을 담을 분류 자체가 없어** 전부 불만으로 계산된 것입니다.

## 핵심 구축 내용

① **판정 엔진** — 범용 감정모델을 인사평가 자료로 재학습 및 제약 알고리즘 추가
② **산출 결과** — **칭찬·중립·불만 워드클라우드**를 각각 생성 (종전에는 라벨 기준 2종·왜곡)
③ **3개 연도 전량 배치 처리** — 2023~2025년 265만 문장을 1건도 남기지 않고 판정

## 주요 성과

✓ **정확도 63.3% → 93.5%**, 그중 **단점 라벨 32.1% → 90.3%** (본 사업이 실제로 푼 문제)
✓ **치명 오류(칭찬↔불만) 7.8% → 1.0%** — 31건 → 4건
✓ **"지적할 점 없음" 48.6만 건(전체의 18.3%) 중 95.9%(46.5만 건)를 중립으로 분리** — 종전에는 전량 불만
✓ **265만 문장 전량 판정 완료** — 칭찬 149.9만(56.5%) · 중립 68.5만(25.8%) · 불만 47.0만(17.7%)

## 인사처 결정 요청

① **채점 표본 400건 사람 재판독 승인** — 실무자 2인 · **약 2시간**. 위 성능 수치의 정답을 정한 주체가 AI이므로 사람 기준선을 확정합니다. **모델을 다시 만드는 작업이 아니라 채점 기준을 검증하는 작업입니다.**
② **종전 업무방식 정의의 제3자 확인** — 구축에 참여하지 않은 팀원 1인. 63.3%라는 비교 기준선을 **정의한 쪽과 평가하는 쪽이 같아** 자기참조 상태입니다.
③ **우선 검토 대상 5,596문장의 확인 절차 승인** — 2025년 75.9만 건 감사에서 규칙이 자동 선별한 의심 문장(고유 기준 5,596 · 반복 포함 9,350).

> ⚠️ **유의** — ① 위 성능 수치의 정답을 정한 주체는 **사람이 아니라 AI 판독**입니다(누적 판정 라벨 12,924건 중 사람 표기 1,511건). ② 93.5%의 95% 신뢰구간은 **90.7~95.5%**, 뒤바뀜 1.0%는 관측 4건 기반으로 **0.4~2.5%**이므로 단일 값으로 인용하지 마십시오. ③ 5,596문장은 **확정 오류가 아니라 후보**이며, 재검토가 필요한 문장 **전량도 아닙니다**(추정 약 3만 건 중 규칙으로 명확히 집어낼 수 있는 부분만 추출). ④ 본 산출물에 대한 **외부 기관 인수검수는 없습니다**(내부 수행). 개인정보는 **가명처리 방식**이며 처리 항목·모듈은 상세 §10-6에 있습니다.
