## 1. 요구사항

1. **정렬 배지**: 작성일·상태·완료일·에픽을 배지로 노출. 클릭 시 `↑ / ↓ / off` 순환. 다중 키 = 클릭 순서 우선순위.
2. **그룹 접기/펼치기**: 에픽 그룹 헤더(`기타`, `model-quality` 등) 클릭 시 토글. 접히면 해당 그룹이 **1줄 통합 밴드**로 표시(통합 간트차트).
3. **연도 맞춤 뷰**: x축을 **해당 연도 1/1 ~ 12/31 고정**, 컨테이너 폭에 맞춰 축소 → **가로 스크롤 없음**.

## 3. 구현 상세

### 3.1 백엔드 (`plans_routes.py`)

- **변경 없음(원칙: 프론트에서 충분)**. 단, 향후 다년도 지원 시 `plans_gantt()` `:742`에 `request.args.get('year')` 수용 + `parse_all_months()`를 연도 폴더 기준 스캔하도록 확장(후속, v1 미포함).
- 연도 값은 프론트에서 `_plans_year()` 등가(현 2026)로 하드픽스하되, 뷰 상단에 연도 표기만.

### 3.2 프론트엔드 (`plans_kanban.html`)

#### 3.2.1 상태(state) 신설
- `let ganttYear = <현재 연도 2026>;` (초기 = `_plans_year()` 등가, `new Date().getFullYear()`로 대체 가능).
- `let sortKeys = [];` — `[{field:'date'|'status'|'end_date'|'epic', dir:'asc'|'desc'}]` 다중 키(클릭 순서).
- `let collapsedSet = new Set();` — 접힌 에픽 이름 집합(`''` = 기타 그룹 포함).
- `let ganttCache = null;` — fetch 결과 캐시(정렬/접기 토글 시 재fetch 방지).

#### 3.2.2 툴바 추가 (view-gantt 패널, `:323` 바로 아래)
- 연도 라벨(고정 표기 `2026` — 드롭다운은 v1 제외).
- 정렬 배지 컨테이너 `#ganttSort`: 배지 4개(`작성일`→`date`, `상태`→`status`, `완료일`→`end_date`, `에픽`→`epic`). 미활성=off, 활성 시 `↑`/`↓` 표시 + 강조 색.
- `전체 접기/펼치기` 토글 버튼(요구 3 시너지: 에픽당 1줄만 남는 초고밀도 뷰).

#### 3.2.3 연도 맞춤 뷰 (요구 3)
- `loadGantt()`의 범위 계산 `:847-857` 교체:
  - `startDate = new Date(ganttYear, 0, 1)`, `endDate = new Date(ganttYear, 11, 31)`.
  - 패딩(+3/-10일) 제거.
- `DAY_W` `:859` 동적 계산:
  - `var scrollW = document.querySelector('.gantt-scroll').clientWidth;`
  - `var LABEL_W = 250;`
  - `var DAY_W = Math.max(2, Math.floor((scrollW - LABEL_W) / 365));` (하한 2px — 그 이하면 미세하나 스크롤 허용 안내). 365일 기준 → 1년 전체가 `scrollW - LABEL_W` px에 fit.
- 월 세그먼트 `:871-884`: 연도 고정이므로 1~12월 정적 루프(매월 1일~말일). 주 틱 `:886-895`: 주 시작일 기준 52~53개.
- `chartWidth = totalDays * DAY_W;` (totalDays = 365 또는 366). `.gantt-grid` `min-width`를 `chartWidth + LABEL_W`로 설정 → 컨테이너 폭과 동일해 가로 스크롤 없음.

#### 3.2.4 정렬 배지 (요구 1)
- 배지 클릭 핸들러(상태 머신):
  - 해당 field가 `sortKeys`에 없음 → `{field, dir:'asc'}` 추가.
  - 있음 & `asc` → `dir`를 `desc`로.
  - 있음 & `desc` → 제거(off).
  - 클릭 순서 = 우선순위(배열 순). UI에 우선순위 번호(1,2) 병기.
- `applySort(tasks, epicOrder)`:
  - `epic` 키는 **그룹 순서** 정렬(에픽 이름 오름/내림).
  - 나머지(`date`/`status`/`end_date`) 키는 **그룹 내 tasks** 정렬.
  - 상태 정렬 순서 상수: `Todo < Doing < Pre-Done < Done < Hold < Drop`(↑시 이 순서, ↓시 역순). `end_date` 없으면 `date`로 fallback.
  - `Array.sort` 체이닝(`sortKeys` 순서대로 비교자 적용).
- `renderGantt()`는 정렬된 `tasks`/`epicOrder`로 `epicGroups` 재구성 후 렌더.

#### 3.2.5 그룹 접기 + 통합 밴드 (요구 2)
- 그룹 헤더(`.gantt-grp`, `:1001-1003`)에 `data-ep="<ep>"` + `onclick="toggleGanttGroup('<ep>')"` 바인딩. `ep`이 `''`(기타)도 구분 가능하게 인코딩(예: 빈문자 대신 `__none__` 매핑 또는 Set에 `''` 그대로, 렌더 시 일치 비교).
- `epicOrder.forEach` 루프 `:998` 분기:
  - **펼침(기존)**: `:1007-1036` 개별 행 그대로.
  - **접힘**: 그룹의 개별 `.gantt-rl` + 개별 막대/점 행 대신 **1줄 통합 밴드**로 대체:
    - 범위: `min(t.date)` ~ `max(t.end_date || t.date)` (그룹 내 전체 계획).
    - 라벨 열: 그룹명 + `n건`만 1줄(하위 pid/summary 축약).
    - 타임라인: `.gantt-bar` 스타일 넓은 밴드, 좌표 `x=getPlanX(minDate)`, 폭 `= (daysBetween(min,max)+1)*DAY_W`. 색 = **에픽 대표색**(보라 `#6f42c1` 계열) 또는 그룹 내 최상위 진행 상태색. 좌측 캡 + `n건` 라벨.
    - **`기타`(`''`) 그룹도 동일**.
- SVG 오버레이(`:1042-1053`): 접힌 그룹의 **내부 선행/CR 간선은 숨김**(스파게티 방지), 펼침 시 복원. 그룹 대표점에는 CR◆/선행 요약 툴팁(후속 정밀화 가능, v1은 숨김으로 충분).
- `전체 접기` 버튼: 모든 에픽을 `collapsedSet`에 추가/제거 토글 → 에픽당 1줄 통합 간트차트.

#### 3.2.6 CSS 추가
- `.sort-badge`(off/asc/desc 3상태 색), `.sort-badge .ord`(우선순위 번호), `.gantt-band`(통합 밴드: 높이 20px, 보라 계열 bg/border, 라벨), `.gantt-grp.collapsed`(접힘 표시, 예: ▸ 아이콘), `.gantt-grp{cursor:pointer}`(클릭 가능 표시).

- **R2** 접힌 그룹 간선 끊김으로 연결 가시성 저하. 대응: v1은 내부 선행/CR선 숨김(스파게티 방지), 그룹 대표점 툴팁은 후속.
- **R3** 다중 정렬 직관성. 대응: 배지에 우선순위 번호(1,2) + 방향 화살표 명시.
- **R4** 연도 드롭다운 부재. 대응: 현재 단일 연도 데이터 구조(`PLANS_DIR` 단일 연도) 한계 → 드롭다운은 다년도 폴더 도입 시 후속(본 계획 v1 범위 아님, §2·§3.1 명시).

## 8. 상위 AI 조언 요청 (open items)

1. 정렬 기본값(미선택 시)을 현재 `epicGroups` 발견 순서(에픽 없음 마지막)로 유지할지, 날짜순으로 할지.
2. 접힌 그룹의 통합 밴드 색을 에픽 대표 보라색으로 할지, 그룹 내 최고 진행 상태색(Doing 우선)으로 할지.
3. 연도 드롭다운을 v1에 포함할지(다년도 폴더 구조 선행 필요) 후속으로 둘지 — 본 계획은 후속로 가정.
