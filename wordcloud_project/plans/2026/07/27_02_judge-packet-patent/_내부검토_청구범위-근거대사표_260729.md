[별첨 1] 청구범위
────────────────────────────────────────────────────────

【청구항 1】(독립항 — 방법)
 인사평가 문장 데이터 중 감정 극성 판정이 어려운 문장으로서, 제1 판정기의 판정 결과와 제2 판정기의 판정 결과가 긍정과 부정으로 상반되거나 긍정 확률과 부정 확률의 차이가 기준값 미만인 문장을 추출하는 단계;
 추출된 문장과, 판정 결과로서 기입되어야 할 출력 항목 및 판정 규칙을 하나의 자기설명 데이터 구조에 결합하여, 상기 데이터 구조에 정의된 상기 출력 항목 형식으로만 응답하도록 구성된 외부 판정 수단에 전달하는 단계;
 상기 외부 판정 수단이 상기 데이터 구조 내에 정의된 출력 항목 형식에 맞추어 판정 결과를 기입하는 단계;
 상기 외부 판정 수단이 확신도 기준을 충족하지 못한다고 표시한 항목만을 선별하여 노출하고 사전 정의된 결정값 집합 중에서 결정을 입력받는 웹 기반 검토 인터페이스를 통해 보완 판정 결과를 획득하는 단계; 및
 상기 자기설명 데이터 구조가 강제하는 동일한 출력 항목 형식을 상기 기입된 판정 결과와 상기 획득된 보완 판정 결과가 공통으로 가지므로, 판정 결과의 출처를 구분하는 별도의 처리 로직 없이 동일한 반영 처리 절차에 의해 원본 시스템의 데이터베이스에 갱신하는 단계를 포함하는,
 인사평가 감정 판정 시스템의 판정 곤란 문장 위임 처리 방법.

【청구항 2】(종속 — 판정 규칙)
 제1항에 있어서, 상기 판정 규칙은 특정 방향의 오분류를 최소화하도록 지시하는 규칙과, 판정 확신도가 낮을 경우 상기 웹 기반 검토 인터페이스로 이관하도록 지시하는 규칙을 포함하는 것을 특징으로 하는 방법.

【청구항 3】(종속 — 웹 기반 검토 인터페이스)
 제1항에 있어서, 상기 웹 기반 검토 인터페이스는, 상기 외부 판정 수단이 확신도 기준 미충족으로 표시한 항목만을 조회하는 로드 단계와, 사전 정의된 결정값 집합 중 하나를 선택해 저장하는 저장 단계로 구성되며, 상기 결정값이 감정 분류에 해당하지 아니하는 값인 경우에는 상기 데이터베이스 갱신 대상에서 제외되는 것을 특징으로 하는 방법.

【청구항 4】(종속 — 마진 사다리)
 제1항에 있어서, 상기 추출 단계는 복수의 임계값 중 최대 임계값으로 1회 추출을 수행하면서 각 문장이 속하는 임계값 구간에 대응하는 표지를 문장별로 부여하여, 재추출 없이 임계값별 결과를 비교 가능하게 하는 것을 특징으로 하는 방법.

【청구항 5】(종속 — 이원 상태 코드 및 반영 지연)
 제1항에 있어서, 상기 판정 결과는 판정 출처와 처리 단계의 조합을 구분하는 상태 코드로 관리되며, 데이터베이스 반영은 사용자의 별도 확정 조작이 있을 때까지 지연되고 상기 확정 조작 시 상기 상태 코드가 반영 완료 상태로 전이되며, 상기 확정 조작 이전에 상기 데이터 구조가 재입력되는 경우에는 이미 반영 완료 상태인 항목만이 재기록되어 반영 결과가 변하지 아니하는 것을 특징으로 하는 방법.

【청구항 6】(종속 — 비식별)
 제1항에 있어서, 상기 추출 단계는 가명 처리되어 저장된 문장을 원복 없이 사용하고, 개인 식별 정보에 대응하는 정규식에 적발된 문장을 상기 데이터 구조에서 제외하여 격리 목록으로 분리하며, 상기 데이터베이스 갱신은 레코드 내부 일련번호와 문장 순번을 키로 하는 in-place 갱신인 것을 특징으로 하는 방법.

【청구항 7】(독립항 — 데이터 구조/기록매체)
 감정 극성 판정이 필요한 문장에 대해, 문장 식별정보·문장 원문·규칙 기반 판정에 의한 극성값·극성 스코어·상기 스코어 간 차이에 대응하는 판정 난이도 구분값을 필드로 포함하며 외부 판정 수단에 제공되는 입력 템플릿;
 상기 입력 템플릿에 결합되어 제공되며, 상기 외부 판정 수단이 준수하여야 할 판정 규칙 및 판정 결과로서 기입되어야 할 출력 항목의 형식과 그 항목의 값에 대한 유효값 범위를 정의하는 출력 템플릿; 및
 처리 주체와 처리 단계의 조합에 대응하는 값을 가지는 상태 코드 필드를 포함하는 구조를 가지며,
 상기 외부 판정 수단 또는 사전 정의된 결정값 집합을 제공하는 웹 기반 검토 인터페이스가 상기 출력 템플릿에 정의된 형식에 맞추어 값을 기입하고, 상기 상태 코드 필드의 값에 따라 컴퓨터가 수행하는 데이터베이스 갱신 처리의 실행 여부 및 반영 대상 레코드가 결정되며, 상기 출력 템플릿에 정의된 형식을 따르는 값이 상기 처리 주체와 무관하게 동일한 갱신 처리 절차에 의해 소비되는,
 데이터 구조를 기록한 컴퓨터로 읽을 수 있는 기록매체.

【청구항 8】(종속 — 입력 템플릿 세부)
 제7항에 있어서, 상기 입력 템플릿은 상기 문장이 속하는 인사평가 항목 구분값 및 상기 판정 난이도 구분값이 극성 불일치와 저마진 중 어느 사유에 해당하는지를 나타내는 값을 필드로 더 포함하는 것을 특징으로 하는 데이터 구조를 기록한 컴퓨터로 읽을 수 있는 기록매체.

【청구항 9】(종속 — 출력 템플릿 세부)
 제7항에 있어서, 상기 출력 템플릿은 극성·확신도·판정근거로 구성된 출력 항목, 및 확신도가 기준을 충족하는지 여부에 따라 서로 다른 다음 처리 단계를 지시하는 상태값의 열거를 포함하는 것을 특징으로 하는 데이터 구조를 기록한 컴퓨터로 읽을 수 있는 기록매체.

【청구항 10】(종속 — 선택적 신뢰도 부착)
 제1항에 있어서, 상기 추출 단계는 별도의 분류 모델이 활성화된 경우에 한하여 각 문장에 상기 모델의 예측 라벨 및 확률 눈금이 보정된 신뢰도를 참고값으로 부가하고, 상기 모델이 비활성이거나 추론에 실패한 경우에는 상기 참고값을 부가하지 아니한 채 이후 단계를 그대로 수행하며, 상기 참고값은 최종 라벨을 결정하지 아니하고 상기 웹 기반 검토 인터페이스로의 이관 판단에만 사용되는 것을 특징으로 하는 방법.
