【청구항 1】(독립항 — 방법)
 인사평가 문장 데이터 중 감정 극성 판정이 어려운 문장으로서, 상기 문장에 대하여 산출된 제1 극성 판정값과 제2 극성 판정값이 긍정과 부정으로 상반되거나 긍정 확률과 부정 확률의 차이가 임계값 미만인 문장을 추출하는 단계;
 추출된 문장과, 판정 결과로서 기입되어야 할 출력 항목 및 판정 규칙을 하나의 자기설명 판정 데이터 구조에 결합하여, 상기 판정 데이터 구조에 정의된 상기 출력 항목 형식으로만 응답하도록 구성된 외부 판정 수단에 전달하는 단계;
 상기 외부 판정 수단으로부터, 상기 판정 데이터 구조 내에 정의된 출력 항목 형식에 따라 판정 결과가 기입된 상기 판정 데이터 구조를 수신하는 단계;
 상기 외부 판정 수단이 사람 판정 대기에 대응하는 상태값으로 표시한 항목만을 선별하여 노출하고 사전 정의된 결정값 집합 중에서 결정을 입력받는 웹 검토 인터페이스로부터, 보완 판정 결과가 기입된 상기 판정 데이터 구조를 획득하는 단계; 및
 상기 자기설명 판정 데이터 구조가 강제하는 동일한 출력 항목 형식을 상기 기입된 판정 결과와 상기 획득된 보완 판정 결과가 공통으로 가지므로, 판정 결과의 출처에 따라 서로 다른 파싱 규칙 또는 반영 규칙을 두지 아니하고, 사람 결정값과 외부 판정 결과가 동일한 필드 우선순위 결정 및 동일한 병합 처리에 의해 원본 시스템의 데이터베이스에 갱신되는 단계를 포함하는,
 인사평가 감정 판정 시스템의 판정 곤란 문장의 위임 판정 및 통합 처리 방법.

【청구항 2】(종속 — 판정 규칙)
 제1항에 있어서, 상기 판정 규칙은 특정 방향의 오분류를 최소화하도록 지시하는 규칙과, 판정 수단이 확신하지 못하는 항목을 사람 판정 대기에 대응하는 상태값으로 표시하여 상기 웹 검토 인터페이스로 이관하도록 지시하는 규칙을 포함하는 것을 특징으로 하는 방법.

【청구항 3】(종속 — 웹 검토 인터페이스)
 제1항에 있어서, 상기 웹 검토 인터페이스는, 상기 외부 판정 수단이 사람 판정 대기에 대응하는 상태값으로 표시한 항목만을 조회하는 로드 단계와, 사전 정의된 결정값 집합 중 하나를 선택해 저장하는 저장 단계로 구성되며, 상기 결정값이 감정 분류에 해당하지 아니하는 값인 경우에는 상기 데이터베이스 갱신 대상에서 제외되는 것을 특징으로 하는 방법.

【청구항 4】(종속 — 마진 사다리)
 제1항에 있어서, 상기 추출 단계는 복수의 임계값 중 최대 임계값으로 1회 추출을 수행하면서 각 문장이 속하는 임계값 구간에 대응하는 표지를 문장별로 부여하여, 재추출 없이 임계값별 결과를 비교 가능하게 하는 것을 특징으로 하는 방법.

【청구항 5】(종속 — 이원 상태 코드 및 반영 지연)
 제1항에 있어서, 상기 판정 결과는 판정 출처와 처리 단계의 조합을 구분하는 상태 코드로 관리되며, 데이터베이스 반영은 사용자의 별도 확정 조작이 있을 때까지 지연되고 상기 확정 조작 시 상기 상태 코드가 반영 완료 상태로 전이되며, 상기 확정 조작 이전에 상기 판정 데이터 구조가 재입력되는 경우에는 이미 반영 완료 상태인 항목만이 재기록되어 반영 결과가 변하지 아니하는 것을 특징으로 하는 방법.

【청구항 6】(종속 — 비식별)
 제1항에 있어서, 상기 추출 단계는 대상자 식별자가 가명으로 치환되어 저장된 레코드의 문장을 원복 없이 사용하고, 개인 식별 정보에 대응하는 정규식에 적발된 문장을 상기 판정 데이터 구조에서 제외하여 격리 목록으로 분리하며, 상기 데이터베이스 갱신은 레코드 내부 일련번호와 문장 순번을 키로 하는 in-place 갱신인 것을 특징으로 하는 방법.

【청구항 7】(종속 — 판정 계통의 이원화 및 무추론 선별)
 제1항에 있어서, 상기 제1 극성 판정값은 상기 문장에 대하여 산출된 스코어에 규칙 보정을 적용한 결과의 부호로부터 도출되고, 상기 제2 극성 판정값은 감정 분류 모델이 상기 문장에 대하여 출력한 긍정·부정·중립 각각의 확률 중 최댓값에 대응하는 분류로부터 도출되어 상기 두 극성 판정값은 그 산출 근거를 서로 달리하며, 상기 확률은 상기 문장이 속하는 평가 문서에 대한 배치 처리 시점에 문장 단위로 저장된 값을 재사용함으로써 상기 추출 단계에서 상기 감정 분류 모델의 재추론이 수행되지 아니하는 것을 특징으로 하는 방법.

【청구항 8】(종속 — 선택적 신뢰도 부착)
 제1항에 있어서, 상기 추출 단계는 별도의 분류 모델이 활성화된 경우에 한하여 각 문장에 상기 모델의 예측 라벨 및 확률 눈금이 보정된 신뢰도를 참고값으로 부가하고, 상기 모델이 비활성이거나 추론에 실패한 경우에는 상기 참고값을 부가하지 아니한 채 이후 단계를 그대로 수행하며, 상기 참고값은 최종 라벨을 결정하지 아니하고 상기 웹 검토 인터페이스로의 이관 판단에만 사용되는 것을 특징으로 하는 방법.

【청구항 9】(독립항 — 판정 데이터 구조/기록매체)
 감정 극성 판정이 필요한 문장에 대해, 문장 반영 키(레코드 내부 일련번호 및 문장 순번)·문장 원문·상기 문장에 대하여 산출된 제1 극성 판정값·긍정과 부정과 중립 각각에 대응하는 확률값·상기 긍정에 대응하는 확률값과 상기 부정에 대응하는 확률값의 차이·상기 차이가 속하는 임계값 구간 표지를 필드로 포함하며 외부 판정 수단에 제공되는 입력 템플릿;
 상기 입력 템플릿에 결합되어 제공되며, 상기 외부 판정 수단이 준수하여야 할 판정 규칙 및 판정 결과로서 기입되어야 할 출력 항목의 형식과 그 항목의 값에 대한 유효값 범위를 정의하는 출력 템플릿; 및
 처리 주체와 처리 단계의 조합에 대응하는 값을 가지는 상태 코드 필드를 포함하는 구조를 가지며,
 상기 출력 템플릿은 외부 판정 수단에 의한 기입 자리와 사전 정의된 결정값 집합을 제공하는 웹 검토 인터페이스에 의한 기입 자리를 동일한 형식으로 정의하고, 상기 상태 코드 필드의 값에 의하여 데이터베이스 갱신 처리의 실행 여부 및 반영 대상 레코드가 특정되며, 상기 출력 템플릿에 정의된 형식을 따르는 값이 상기 기입 자리의 구분과 무관하게 동일한 갱신 처리 절차에 의해 소비되도록 구성된,
 판정 데이터 구조를 기록한 컴퓨터로 읽을 수 있는 기록매체.

【청구항 10】(종속 — 입력 템플릿 세부)
 제9항에 있어서, 상기 입력 템플릿은 상기 문장이 속하는 인사평가 항목 구분값 및 상기 문장이 위임 대상으로 판별된 사유가 극성 불일치와 저마진 중 어느 것인지를 나타내는 값을 필드로 더 포함하는 것을 특징으로 하는 판정 데이터 구조를 기록한 컴퓨터로 읽을 수 있는 기록매체.

【청구항 11】(종속 — 출력 템플릿 세부)
 제9항에 있어서, 상기 출력 템플릿은 극성·확신도·판정근거로 구성된 출력 항목, 및 판정 수단의 확신 여부에 따라 서로 다른 다음 처리 단계를 지시하는 상태값의 열거를 포함하는 것을 특징으로 하는 판정 데이터 구조를 기록한 컴퓨터로 읽을 수 있는 기록매체.

【청구항 12】(종속 — 절차의 자기설명성 : 단계 정의 및 진행 상태)
 제9항에 있어서, 상기 판정 데이터 구조는 추출·판정·반영의 각 처리 단계에 대하여 해당 단계의 수행 주체, 완료 여부 및 해당 단계에서 수행하여야 할 작업의 지시문을 정의하는 단계 정의 필드와, 현재의 처리 단계 및 단계별 처리 이력을 기록하는 진행 상태 필드를 더 포함하며, 이로써 상기 판정 데이터 구조를 수신한 주체가 별도의 절차 문서 또는 상태 조회를 위한 연동 없이 상기 판정 데이터 구조만으로 자신이 수행할 단계와 그 다음 단계의 수행 주체를 특정할 수 있도록 구성된 것을 특징으로 하는 판정 데이터 구조를 기록한 컴퓨터로 읽을 수 있는 기록매체.

【청구항 13】(독립항 — 시스템)
 인사평가 문장 데이터를 저장하는 데이터베이스;
 상기 데이터베이스로부터, 문장에 대하여 산출된 제1 극성 판정값과 제2 극성 판정값이 긍정과 부정으로 상반되거나 긍정 확률과 부정 확률의 차이가 임계값 미만인 문장을 추출하는 추출부;
 추출된 문장 및 그 반영 키와, 판정 수단이 준수하여야 할 판정 규칙, 판정 결과가 기입되어야 할 출력 항목의 형식 및 유효값, 그리고 처리 단계의 정의 및 진행 상태를 하나의 자기설명 판정 데이터 구조로 결합하여 생성하는 판정 데이터 구조 생성부;
 생성된 상기 판정 데이터 구조를 파일로 제공하고, 상기 출력 항목의 형식에 따라 판정 결과가 기입된 상기 판정 데이터 구조를 수신하여 보관하는 위임 인터페이스부;
 보관된 상기 판정 데이터 구조 중 사람 판정 대기에 대응하는 상태값을 가지는 항목만을 선별 조회하여 표시하고, 사전 정의된 결정값 집합 중 하나를 입력받아 동일한 상기 판정 데이터 구조에 기록하는 웹 검토 인터페이스부; 및
 상기 판정 데이터 구조에 기입된 판정 결과와 보완 판정 결과에 대하여, 그 출처에 따라 서로 다른 파싱 규칙 또는 반영 규칙을 두지 아니하고 동일한 필드 우선순위 결정 및 동일한 병합 처리에 의하여 상기 데이터베이스를 갱신하되, 사용자의 확정 조작이 있을 때까지 상기 갱신을 지연시키고 상기 확정 조작 시 상기 상태값을 반영 완료 상태로 전이시키는 반영부를 포함하며,
 상기 추출부, 상기 판정 데이터 구조 생성부, 상기 위임 인터페이스부, 상기 웹 검토 인터페이스부 및 상기 반영부는 상기 자기설명 판정 데이터 구조를 매개로 처리 상태와 판정 결과를 공유하는,
 인사평가 감정 판정 시스템.

【청구항 14】(종속 — 제9항 : 선별 기준의 유예)
 제9항에 있어서, 상기 임계값 구간 표지는 복수의 임계값 중 최대 임계값을 적용하여 1회 수행된 추출에서 각 문장의 상기 차이가 속하는 구간에 따라 문장별로 부여된 것이며, 상기 판정 데이터 구조는 상기 구간 표지별 항목 건수를 집계한 필드를 더 포함하여, 추출을 다시 수행하지 아니하고 임계값별 결과를 비교하여 적용할 임계값을 사후에 선택할 수 있도록 구성된 것을 특징으로 하는 판정 데이터 구조를 기록한 컴퓨터로 읽을 수 있는 기록매체.

【청구항 15】(종속 — 제9항 : 원본 반영의 유예)
 제9항에 있어서, 상기 상태 코드 필드는 작업이 완료되었으나 데이터베이스에 반영되지 아니한 상태에 대응하는 값과 데이터베이스 반영이 완료된 상태에 대응하는 값을 처리 주체별로 구분하여 가지며, 상기 작업 완료에 대응하는 값을 가지는 항목은 사용자의 확정 조작이 있을 때까지 상기 데이터베이스 갱신 처리의 대상에서 제외되고 상기 확정 조작 시 상기 반영 완료에 대응하는 값으로 전이되며, 상기 확정 조작 이전에 상기 판정 데이터 구조가 다시 입력되는 경우에는 이미 상기 반영 완료에 대응하는 값을 가지는 항목만이 재기록되어 반영 결과가 변하지 아니하도록 구성된 것을 특징으로 하는 판정 데이터 구조를 기록한 컴퓨터로 읽을 수 있는 기록매체.

※ 청구항 14·15 는 청구항 4(마진 사다리)·청구항 5(이원 상태 코드 및 반영 지연)의 **동작을 청구항 9(판정 데이터 구조 독립항) 계열에서 다시 한정한 것**이다. 청구항 4·5 는 제1항 종속으로 그대로 유지하며, 14·15 는 그 삭제·대체가 아니라 추가이다. 목적은 독립항 1 이 무효로 되더라도 신고서 §3(1) 핵심 3(확정의 유예와 그 유예 상태의 동봉)이 9항 계열로 독자 생존하는 경로를 두는 데 있다. 두 청구항이 인용하는 필드(임계값 구간 표지·상태 코드)는 이미 청구항 9 본체에 기재되어 있으므로 뒷받침은 확보되어 있다.

※ **실측 유의** — 구현상 구간 표지(`margin_band`)는 저마진 문장에 대하여는 `'0.05'/'0.10'/'0.15'` 중 하나가, 제1·제2 극성 판정값이 상반되는 문장에 대하여는 `'flip'` 이 부여된다(A 199행). 청구항 9 본체와 청구항 14 는 이를 「상기 차이가 속하는 임계값 구간 표지」로만 표현하고 있어, `flip` 표지를 문언에 명시할 것인지는 청구항 9 와 함께 변리사 협의에서 정한다.

※ 본 별첨의 청구범위는 **초안**이며 확정된 권리범위가 아니다. 청구항 수·카테고리별 배치·발명의 단일성 판단은 변리사 협의에서 확정한다(미결 D-8·D-9 참조).
