## 4. 핵심 버그 기록

### Bug: ZIP `arcname` 파일명 충돌

- **증상**: ZIP 다운로드 시 직원 1명의 통합/긍정/부정 3종 파일 중 마지막 1개만 ZIP에 포함됨
- **원인**: `arcname = os.path.basename(fp)` 사용 시 `outputs/배포/통합/홍길동_2024.png`, `outputs/배포/긍정/홍길동_2024.png`, `outputs/배포/부정/홍길동_2024.png` 모두 `홍길동_2024.png`로 동일 arcname → 덮어씀
- **수정**: `arcname = os.path.relpath(fp, OUTPUTS_DIR_PATH).replace('\\', '/')` — ZIP 내부 경로 `배포/통합/홍길동_2024.png` 형태로 디렉토리 구조 유지
