## 2. 문제 정의

### 버그 #1: 대용량 파일 업로드 시 로딩 화면 미표시

- **증상**: 데이터 업로드에서 파일 선택 후 로딩 화면이 없어, 용량이 큰 경우 장기 대기 중 오류로 판단할 수 있음
- **재현 조건**: 
  - 메타데이터 생성 화면 → 데이터 업로드 섹션
  - 용량이 큰 파일 선택 (예: 100MB+)
  - 파일 로딩 완료까지 UI에 진행 표시 없음

### 버그 #2: 폴더 선택 시 화면 공백

- **증상**: 폴더 선택 시 화면에 아무것도 출력되지 않음 (예: 선택된 폴더 경로, 상태 메시지 등)
- **재현 조건**: 
  - 메타데이터 생성 화면 → 폴더 선택 버튼 클릭
  - 폴더 선택 완료 후 UI 상태 미반영

## 6. 테스트/검증 계획

### 단위 테스트 대상 (프론트엔드)

| 시나리오 | 검증 항목 | 기대 결과 |
|---------|---------|---------|
| 파일 업로드 시작 | 로딩 스피너 표시 여부 | 스피너가 화면에 표시됨 |
| 파일 업로드 완료 | 로딩 스피너 숨김 여부 | 스피너가 사라지고 폼 데이터 표시됨 |
| 파일 업로드 오류 | 오류 메시지 표시 | 오류 알림이 표시됨 |
| 폴더 선택 완료 | 선택 경로 표시 | 폴더 경로가 텍스트로 표시됨 |
| 배치 명칭 입력 | 라벨 자동 입력 | 핸드오프 코퍼스, eval 필드가 자동 채워짐 |
| 라벨 수동 수정 | 수동 변경 가능 여부 | 사용자가 자동 채운 라벨을 수정 가능 |

### 통합 테스트 시나리오

1. **Golden Path**: 파일 선택 → 로딩 표시 → 업로드 완료 → 폴더 선택 → 배치 명칭 입력 → 라벨 자동 입력 → 저장
2. **Error Path**: 대용량 파일 업로드 → 타임아웃 또는 오류 발생 → 오류 메시지 표시 → 재시도 가능
3. **Manual Override**: 배치 명칭 입력 → 라벨 자동 입력 → 사용자가 라벨 수동 변경 → 저장
