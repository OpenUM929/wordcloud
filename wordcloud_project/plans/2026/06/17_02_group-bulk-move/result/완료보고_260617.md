## 동작 방식

1. 제출용 배포(워드클라우드 생성) 실행 → `_deployResults`에 전 직원 결과 보유.
2. 요약바 버튼 클릭 → `_deployResults` 전량에서 해당 카테고리 평탄화(긍/부/중은 top-level+`row_results`, 욕설은 `profanity_summary`).
3. 확인(confirm) → `save-bulk` 1회 POST → `acquired_sentences` 적재(분류 시점 KoTE 값 동반).
4. "추가 N / 건너뜀 N" 토스트 + `/acquired-data` 링크.
