## 3. 구현 상세

### 3.1 백엔드

**`deploy_session_service.py` — `retry_failed_tasks(session_id)`**
- `UPDATE deploy_tasks SET status='pending', error_message=NULL ... WHERE status='failed'`
- `UPDATE deploy_sessions SET status='running', completed_at=NULL`
- 동일 트랜잭션 내에서 처리하여 일관성 보장

**`perspective_routes.py` — `/deploy-session/retry` (POST)**
- `session_id` 바디 파라미터 필수 검증
- `get_session_progress()`로 세션 존재 여부 확인 (404 처리)
- `_is_admin()` 체크
- `retry_failed_tasks(session_id)` 호출 후 `{success: True, session_id}` 반환

### 3.2 프론트엔드

**`openIdInputModal(failedIds, sessionId = null)`**
- `sessionId`가 truthy면:
  - `ta.style.minHeight = '400px'`
  - `modalContent.style.maxHeight = '95vh'`
  - `window._retrySessionId = sessionId`
  - 타이틀을 "✏️ 실패 사번 수정 (재시도)"로 변경
- 그렇지 않으면 기본값 복원

**`confirmIdInput()`**
- 매칭 완료 후 `_csvEmployeeIds = matchedIds` 설정 직후:
  ```javascript
  if (window._retrySessionId) {
      saveDeploy(window._retrySessionId);
      window._retrySessionId = null;
  }
  ```

**`saveDeploy(resumeSessionId)`**
1. `sessionId`가 존재하면 (`resumeSessionId`):
   - `/deploy-session/tasks?session_id=`로 기존 태스크 전체 조회
   - `status==='completed'`이고 `result_path`가 있으면 JSON 파싱 → `existingSuccessData.push()`
   - `status==='failed'`이면 `existingFailData.push()`
   - `/deploy-session/retry` POST 호출로 failed 태스크를 pending으로 리셋
   - `total = existingSuccessData.length + existingFailData.length`
2. `successData = [...existingSuccessData]`, `failData = [...existingFailData]`로 초기화
3. `doneCount = existingSuccessData.length`, `failCount = existingFailData.length`로 초기화
4. chunk 루프는 `allocate_chunk`가 `pending` 상태만 반환하므로 **실패분만 자동 처리**

**`processOne()` — 재시도 성공 시 failData 제거**
```javascript
if (d.success) {
    // ... 기존 successData.push ...
    const fi = failData.findIndex(f => f.employee_id === eid);
    if (fi !== -1) {
        failData.splice(fi, 1);
        failCount--;
    }
}
```

**`renderDeployComplete()` — summary-bar 버튼**
- `failCountItems > 0 && window._lastDeploySessionId` 조건 만족 시:
  ```html
  <button onclick="openIdInputModal([...], 'session-uuid')"
          style="...background:#dc3545...">✏️ 실패 사번 수정 →</button>
  ```
- summary-bar 우측에 배치, 갤러리 링크와 병존

**`renderDeployComplete()` — 하단 버튼 `sessionId` 전달**
```javascript
const _sid2 = window._lastDeploySessionId ? `,'${window._lastDeploySessionId}'` : '';
h += `<button onclick="openIdInputModal(${safeJson}${_sid2})">...`;
```
