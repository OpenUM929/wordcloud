## 동작 방식

1. 게시판에서 "데이터 가져오기" → 기본/정제 CSV 선택.
2. 중복 처리 선택(덮어쓰기/건너뛰기) → 업로드.
3. `acquired_sentences`에 적재 → "추가 N / 건너뜀 N" 알림 → 목록 자동 새로고침.
4. 정제 메타(KoTE 점수·규칙)는 기존 "정제 CSV" 내보내기/후속 화면 측정에서 재계산(적재 시점엔 기본 컬럼만).
