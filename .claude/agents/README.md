# 서브에이전트 카탈로그 (MSYS 판)

> 갱신일: 2026-07-22 · MSYS 개발 이력(V1.x → REQ-2604/2605 시리즈, 커밋 약 100건)과 `.clinerules` 지침을 근거로 재설계.
> 원본 7종은 wordcloud 프로젝트에서 가져왔으며, 이 중 5종을 MSYS에 맞게 개조하고 2종을 신규 추가했다.
> 각 파일은 Claude Code 서브에이전트 정의(`.claude/agents/*.md`)이며, 다른 프로젝트에 복사해 재사용할 수 있다.

## 구성

### MSYS 적용 (7종)

| 에이전트 | 역할 | 근거가 된 MSYS 개발 이력 |
|----------|------|--------------------------|
| `plan-writer` | 계획서 작성 (검증된 사실만, msys/plans/ 규약) | Plan Mode 지침, 계획서 기반 착수 규약 |
| `bug-diagnostician` | 버그 진단 (증상→로그→재현, 읽기 전용) | KST/UTC·페이징·init() 중복 등 반복 버그 다수 — 다발 버그 점검표 내장 |
| `ui-builder` | UI 구현 (디자인 규모 판단, 공통 모듈 보호) | 전체 커밋의 절반 이상이 UI 작업. 오버플로우·Tailwind 미지원 클래스 사고 |
| `api-builder` | **[신규]** 백엔드 구현 (routes→service→dao→mapper 계층, 시간·네이밍 표준) | 계층형 백엔드 + Python 3.9 호환성 사고, 상태코드 예약 대역 사고 |
| `cr-scribe` | **[신규]** 커밋·CR 절차 (CR ID 채번, FP 산정, 서브모듈 분리 커밋) | 커밋마다 CR 보고서·릴리즈 노트·FP 산정·지침 동기화가 강제되는 무거운 절차 |
| `report-writer` | 산출물 문서 (A4 규격, 캡처 규칙, 수치 재계산) | 구축완료보고서·FP 분석표·운영자 메뉴얼 + 깨진 참조 사고 |
| `fp-estimator` | **[신규]** 기능점수(FP) 산정·검증·개발비 (교육자료 우선, 소스 전수 실증, 정합성 대사, 보정계수 산식) | FP 산정 지침 v2.1 + 재발방지 10개 사고(수치 승계·개수 추정·보정계수 오적용 등) |
| `deploy-verifier` | 배포 검증 (msys.zip 포함/제외 실물 확인) | pre-commit zip 빌드, db_config.py 포함 예외 규칙 |

## 설계 원칙

1. **지침 잠금 규칙을 에이전트 본문에 내장** — 서브에이전트는 메인 대화의 컨텍스트를 물려받지 않으므로, 반복 사고를 일으킨 규칙(레거시 보호 승인 절차, 서버 무단 실행 금지, 파괴적 git 명령 금지, 저장소 분리 커밋 등)을 정의 안에 직접 박았다. 단, 상세 규칙은 `.clinerules` 정본 경로를 명시해 이중 관리(지침 사본화)를 피했다.
2. **읽기/쓰기 권한 분리** — 진단(`bug-diagnostician`)과 검증(`deploy-verifier`)은 읽기 전용 도구만 부여해 "분석 중 임의 수정" 사고를 구조적으로 차단.
3. **실패 이력의 체크리스트화** — 실제 발생한 사고(KST 변환 누락, Tailwind 미지원 클래스, Python 3.10 문법, CD코드 예약 대역 등)를 해당 에이전트의 우선 점검 목록으로 변환했다. 프로젝트를 운영하며 이 목록을 누적 갱신한다.
4. **이식성 절 분리** — 각 파일 하단 "다른 프로젝트 이식 시" 절에 프로젝트 종속부(경로·스크립트·규약)와 공통 원칙을 구분했다. 새 프로젝트에서는 종속부 절만 교체하면 된다.

## 다른 프로젝트로 공유하는 방법

1. 이 폴더의 `*.md`를 대상 프로젝트 `.claude/agents/`에 복사
2. 각 파일의 "이식 시 교체" 표시 절(저장 규약·다발 버그 목록·빌드 명령 등)을 대상 프로젝트에 맞게 교체
3. 대상 프로젝트에 `.clinerules`가 없으면 본문 내 지침 경로 참조를 해당 프로젝트 규칙 문서로 치환 (지침 자체가 없으면 잠금 규칙 본문만으로 동작함)
4. 도메인 특화 에이전트(`sentiment-judge`, `dataset-curator`)는 해당 도메인이 없으면 제외
5. 사용: 메인 대화에서 "서브에이전트로 ~해줘" 또는 에이전트 이름을 지정해 위임

## 권장 협업 흐름 (MSYS 표준 작업 사이클)

```
요청 접수
 ├─ 버그 신고("안 돼요") → bug-diagnostician (진단만) → 수정안 승인 후 ui-builder/api-builder가 구현
 ├─ 신규 기능           → plan-writer (계획서) → 사용자 "수행" → ui-builder + api-builder
 ├─ 문서 요청           → report-writer
 └─ "커밋해줘"          → cr-scribe (CR ID·보고서·커밋) → 배포 시 deploy-verifier
```
